# STOCK AI

日本株・米国株を対象とした、JavaScript独自データ分析型の投資判断支援アプリです。Pythonは使用せず、自動売買も行いません。

## 開発方針
- HTML/CSS/JavaScriptの画面とNode.jsの定期処理で構成
- 有料AI・有料API・有料サーバーに依存しないことを目標にする
- 無料データの取得元・取得時刻・遅延状態を明示する
- データ欠損・古いデータでは購入判断を出さない
- 予測は複数シナリオと不確実性を表示し、時系列バックテストで検証する
- モデル改善は未使用データで検証し、悪化時は採用しない
- Firebase Spark無料枠を優先する
- APIキー・秘密情報を公開HTMLへ保存しない

## 実装済み
- Node.jsプロジェクト設定（外部ランタイム依存なし）
- 株価データの共通形式への正規化
- OHLCV検証、重複日付検出、日付順整列、データ鮮度判定
- SMA・EMA・RSIのテクニカル指標
- Node.js標準テストランナーによる自動テスト
- GitHub Actionsによるテスト自動実行

## 未実装
- 実データプロバイダー接続
- ファンダメンタルズ・市場・リスク分析
- 総合スコアと銘柄スクリーニング
- 株価予測・バックテスト・モデル改善
- 楽天証券CSV取込・通知・Firebase連携

## テスト
Node.js 20以降で以下を実行します。

```bash
npm test
```

## 起動
GitHub Pagesで公開する場合は、リポジトリのPages設定でmainブランチのルートを公開元に設定します。ローカルでは簡易HTTPサーバー経由でindex.htmlを開いてください。

## 注意
無料データには遅延・利用回数・銘柄カバレッジ・利用条件の制限があります。データソースを確認するまでは売買判断に利用できると保証しません。本アプリは情報整理・分析支援用であり、投資助言や利益を保証するものではありません。
