# STOCK AI

日本株・米国株を対象とした、独自データ分析型の投資判断支援アプリです。自動売買は行いません。

## 開発方針
- 無料データを優先し、取得元・取得時刻・遅延状態を明示する
- データ欠損・古いデータでは購入判断を出さない
- 予測は複数シナリオと不確実性を表示し、時系列バックテストで検証する
- モデル改善は未使用データで検証し、悪化時は採用しない
- Firebase Spark無料枠を優先する
- APIキー・秘密情報を公開HTMLへ保存しない

## 現在の開発段階
Phase 1: UI基盤を構築中。株価データ・分析・予測はまだ未実装です。画面に実在しない株価や推奨銘柄は表示しません。

## 起動
GitHub Pagesで公開する場合はリポジトリのPages設定で main ブランチのルートを公開元に設定します。ローカルでは簡易HTTPサーバー経由で index.html を開いてください。

## 注意
本アプリは情報整理・分析支援用であり、投資助言や利益を保証するものではありません。
