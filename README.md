# STOCK AI

日本株・米国株を対象とした、JavaScript独自データ分析型の投資判断支援アプリです。Pythonは使用せず、自動売買も行いません。

## 方針
- HTML/CSS/JavaScript + Node.js標準機能のみ
- 有料AI・有料API・有料サーバーに依存しない構成を目標にする
- 無料データの取得元・取得時刻・遅延・調整方式を明示
- データ欠損・古いデータ・未調整価格では購入判断を制限
- Firebase Sparkを維持する方針
- APIキーはGitHub Actions secretsのみ。公開HTML・コミットに含めない

## 実装済み
- 株価データ正規化・検証・鮮度判定
- SMA / EMA / RSI
- 年次財務分析、100点評価、3シナリオ価格予測、予測誤差評価
- 統合分析パイプライン
- J-Quants V2 / SEC EDGAR / Alpha Vantageのデータ取得アダプター
- 日次データ取得スクリプトとGitHub Actionsワークフロー
- 予測履歴の端末内保存、将来株価との自動照合、誤差率・方向一致率・レンジ的中率の集計
- 楽天証券などの日本語・英語CSVから保有銘柄を読み込み、端末内に保存する機能
- 公開株価スナップショットと保有株数を照合した評価額・損益・前日比・通貨別資産配分・集中リスク分析
- 日本株はJ-Quants Freeの年次決算サマリー、米国株はSEC Company Factsの10-Kから売上・利益・EPS・資産・負債・営業CF等を取得し、財務健全性を分析
- 年次EPSを使ったPER、推定可能な場合のPBR、EPS×PER倍率による参考価格シナリオ（PER 10/16/22倍）を表示

## データソースの制限
- J-Quants Free: 12週間遅延、約2年分の履歴
- Alpha Vantage Free: 25 requests/day。日足Compactは直近100件。今回の実装は未調整OHLCV
- SEC EDGAR: 企業提出書類の財務データ。リアルタイム株価ではない
- 無料データはリアルタイム・無制限・全銘柄を保証しない

## 予測精度の検証

予測時点の価格・予測値・予測レンジをブラウザーのlocalStorageに保存し、後日公開された株価データの該当営業日と照合します。短期・中期・長期の予測を別々に評価します。各期間で検証済み予測が5件以上になると、実績/予測比率の中央値を使った補正を有効にします。補正幅は最大±10%に制限し、十分な検証件数がない間は元の予測を維持します。これは限定的な統計補正であり、機械学習や予測精度の保証ではありません。履歴は利用中のブラウザー・端末内だけに保存され、別端末とは同期されません。ブラウザーデータを消去すると履歴も消えます。将来データが未到達の予測は「検証待ち」として保持します。

## 保有資産CSV

保有資産タブでCSVを選択して読み込みます。UTF-8を優先し、読み込めない場合はShift-JISとして再解析します。銘柄コード・保有数量・取得単価・現在値・評価額・評価損益などの列名を自動判定します。データはブラウザーのlocalStorageに保存され、外部サーバーには送信されません。ブラウザーのデータ消去や端末変更では引き継がれないため、元の証券会社CSVを保管してください。列名や出力内容は楽天証券のCSV種別・時期によって異なるため、認識されない場合はサンプルCSVに合わせた列名追加が必要です。日本円と米ドルは換算せず別々に集計します。

## 保有資産の株価照合・リスク分析

取り込んだ保有数量・取得単価を公開済み株価データと照合し、最新取得価格、評価額、評価損益、前日比、通貨別の評価額・損益率、上位3銘柄の集中度を計算します。JPYとUSDは換算せず別集計です。公開株価データに存在しない銘柄はCSV取込値を残し、データなしとして警告します。データ日付が5日を超える場合は古いデータとして表示します。J-Quants Freeの日本株データは約12週遅延、Alpha Vantage Freeの米国株データは日次・未調整価格です。未調整価格では分割等による損益の歪みがあり得るため警告を表示します。ここでいう評価額は取得できた日次終値による参考計算であり、リアルタイム評価額や証券口座の公式残高ではありません。

## 財務データの取得と分析

日本株はJ-Quants API V2の`/v2/fins/summary`を利用し、`CurPerType=FY`の通期開示だけを採用します。四半期累計値と通期値を混在させません。Freeプランは株価・財務情報ともに約12週間遅延します。取得項目は売上高、営業利益、純利益、EPS、総資産、純資産、営業キャッシュフロー、現金同等物です。負債は総資産−純資産からの派生値として扱い、個別の負債項目を取得したかのようには表示しません。

米国株はSEC Company Factsの10-Kデータを利用します。売上高・営業利益・純利益・希薄化EPS・総資産・総負債・営業CFに加え、取得可能な場合は設備投資、粗利益、現金、流動資産・負債、純資産、長期負債を取得します。期間項目は開始日から終了日が300〜400日の年次データだけを採用し、10-Kに含まれる四半期値を年次値として誤認しないようにしています。

フリーキャッシュフローは営業CF−設備投資（設備投資額の絶対値）で計算します。データがない項目は推定せず欠損のままです。会計基準・連結範囲・単位が異なる企業間比較には注意が必要です。

## 設定
`config/market-universe.json` を編集して対象銘柄を指定し、GitHub Actions secretsにAPIキー等を設定してください。詳細は `docs/MARKET_DATA_AUTOMATION.md`。

## テスト
Node.js 20以降で `npm run test:engine`。

## 注意
本アプリは分析支援であり、投資助言・利益保証・自動売買を行いません。


## 企業価値・価格シナリオ

銘柄カードと保有銘柄レビューに、取得できた通期EPSを使った参考PERを表示します。純利益÷EPSから発行株式数を概算でき、純資産も取得できる場合に限りPBRを計算します。PERシナリオはEPS×10倍・16倍・22倍の仮定値であり、業種別の適正株価・目標株価ではありません。EPSが欠損・赤字・比較不能の場合はPERやシナリオを表示しません。実際の市場価格と財務基準日のずれ、会計基準、株式数の変化に注意してください。
